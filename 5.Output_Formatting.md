# Output Formatting

Python uses the `print()` function to display output. We can pass multiple arguments to `print()` and use f-strings to include variable values in text.

## Example

```python
name = "Kedar"
age = 27

print("Name:", name, "Age:", age)
print(f"My name is {name} and I am {age}.")
```

## How it works

The first statement prints multiple arguments separated by spaces. The f-string inserts the values of `name` and `age` directly into the sentence.
