# 📝 Python Integer Literals — Quick Notes

- **Literal = direct value** in code → decides data type.  
- **Integers (`int`)** → digits `0–9` only.  
  - ❌ No commas, spaces, or periods.  
- **Readable numbers** → use `_` (since Python 3.6).  
  - Example: `11_111_111` = `11111111`.  
- **Negative** → add `-` before number.  
- **Positive** → `+` optional (`+10` = `10`).  
- **Default type** → `int`.

---

## 🔢 Integer Literal Forms

| Form        | Example     | Meaning         |
|-------------|-------------|-----------------|
| Decimal     | `25`        | Base‑10 (normal)|
| Binary      | `0b11001`   | Base‑2          |
| Octal       | `0o31`      | Base‑8          |
| Hexadecimal | `0x19`      | Base‑16         |

---

👉 **Key takeaway:**  
Write integers as plain digits, use `_` for clarity, `-` for negatives, `+` optional for positives.  
Know the prefixes: `0b` (binary), `0o` (octal), `0x` (hex).
