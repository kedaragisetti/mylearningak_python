## Featured Project

### [Tic-Tac-Toe (CLI Game)](./project_tic-tac-toe)
A command-line Tic-Tac-Toe game (`O` vs. computer `X`) built with Python's standard library, demonstrating 2D lists, coordinate tuple mapping, modular functions, and input validation.
