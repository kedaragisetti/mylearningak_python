# 📝 Python Floats

- **Float = number with decimal part** → e.g. `2.5`, `-0.4`.  
- **Dot (.) not comma** → `2.5` ✅, `2,5` ❌.  
- **Leading/trailing zero optional** → `.4` = `0.4`, `4.` = `4.0`.  
- **Int vs Float** → `4` (int), `4.0` (float).  
- **Scientific notation** → use `e`/`E`.  
  - Example: `3E8` = `3 × 10^8`.  
  - Example: `6.62607E-34` (Planck’s constant).  
- **Exponent must be int**, base can be int or float.  
- **Python may display floats differently** (sometimes scientific form).

---

👉 **Key takeaway:**  
Floats = numbers with decimals or `e` notation. Dot makes a float, `e` handles very large/small values.
