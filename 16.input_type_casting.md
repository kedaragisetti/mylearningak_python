# Talking to a Computer – input(), Type Casting, String Ops

## input() Basics
- `print()` → sends data to console.  
- `input()` → gets data from console (keyboard, etc.).  
- Always returns a **string**.  
- Must assign result to a variable, else data is lost.

Example:
```python
print("Tell me anything...")
anything = input()
print("Hmm...", anything, "... Really?")
```

👉 Output:
```
Tell me anything...
hi how are you?
Hmm... hi how are you? ... Really?
```

---

## 📌 input() with Prompt
- `input()` can display a message directly.

```python
anything = input("Tell me anything... ")
print("Hmm...", anything, "...Really?")
```

---

## ⚠️ Result of input()
- Always a **string** → cannot be used directly in math.

```python
anything = input("Enter a number: ")
something = anything ** 2.0   # ❌ Error
```

👉 Error:
```
TypeError: unsupported operand type(s) for ** or pow(): 'str' and 'float'
```

---

##  Type Casting
- Use `int()` or `float()` to convert input string → number.

```python
num = float(input("Enter a number: "))
print(num, "to the power of 2 is", num ** 2)
```

👉 Output:
```
Enter a number: 1
1.0 to the power of 2 is 1.0
```

---

## Example: Hypotenuse with input()
```python
a = float(input("Input first leg length: "))
b = float(input("Input second leg length: "))
hypo = (a ** 2 + b ** 2) ** 0.5
print("Hypotenuse length is", hypo)
```

👉 Output:
```
Input first leg length: 5
Input second leg length: -5
Hypotenuse length is 7.0710678118654755
```

Note: program doesn’t check for negative values yet.
