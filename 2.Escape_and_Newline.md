# Escape and Newline Characters

Escape characters are used to format text inside strings. `\n` moves text to a new line, `\t` adds a tab space, and `\\` prints a backslash.

## Example

```python
print("Hello\nWorld")
print("Hello\tWorld")
print("C:\\Python")
```

## How it works

- `\n` prints Hello and World on separate lines.
- `\t` adds spacing between Hello and World.
- `\\` displays a single backslash.
