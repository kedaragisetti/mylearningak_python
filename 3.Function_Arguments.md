# Function Arguments

Arguments are values passed to a function. Positional arguments use the order of the values, while keyword arguments specify the parameter names.

## Example

```python
def introduce(name, age):
    print(name, age)

introduce("Kedar", 27)
introduce(age=27, name="Kedar")
```

## How it works

The first function call passes values by position. The second passes values using parameter names, so their order can change.
