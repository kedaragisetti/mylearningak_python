# 📝 Python `print()` — Quick Notes

- **Built-in** → shows output on screen.  
- **Call** → `print()` with arguments inside `()`.  
- **Strings** → text in `' '` or `" "`.  
- **Order** → runs instructions top → bottom.  
- **Escape chars** → `\n` newline, `\t` tab.  
- **Positional args** → order matters.  
- **Keyword args** → control behaviour (`sep`, `end`).  
  - `sep` → separator (default space).  
  - `end` → ending (default newline).  

---

👉 **Key takeaway:**  
Use `print()` for output. Quotes define strings. `\n`/`\t` for formatting. `sep` sets separators, `end` sets line ending.
