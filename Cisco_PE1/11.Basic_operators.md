# 📝 Python Basic Operators

- **Arithmetic operators** → `+`, `-`, `*`, `/`, `//`, `%`, `**`.  
- **Expressions** = data + operators.  
- **Exponentiation (`**`)** → power.  
  - int ** int → int  
  - float involved → float result  
- **Multiplication (`*`)** → standard product.  
- **Division (`/`)** → always float result.  
- **Floor division (`//`)** → integer division, rounded down (towards lesser integer).  
- **Modulo (`%`)** → remainder after division.  
- **Addition (`+`)** → sum.  
- **Subtraction (`-`)** → difference.  
  - Binary `-` → subtraction.  
  - Unary `-` → negation.  
  - Unary `+` → keeps sign (rarely useful).  

---

## 🔢 Example Code

```python
# Exponentiation
print(2 ** 3)
print(2.0 ** 3)

# Multiplication
print(2 * 3)
print(2.0 * 3)

# Division
print(4 / 2)
print(1 / 2)

# Floor division
print(4 // 2)
print(3 // 2)
print(-3 // 2)

# Modulo
print(14 % 4)
print(12 % 4.5)

# Addition & subtraction
print(2 + 2)
print(5 - 3)
print(-8)     # unary minus
print(+2)     # unary plus
```

## Floor Division //

Meaning: Performs integer division but rounds down (toward the lesser integer).

Examples:

```python
print(4 // 2)   # 4 divided by 2 = 2 exactly → result is 2
print(3 // 2)   # 3 divided by 2 = 1.5 → floor rounds down → result is 1
print(-3 // 2)  # -3 divided by 2 = -1.5 → floor rounds down to lesser 
```
- integer → result is -2

-> Key point: For negative numbers, “rounding down” means going more negative. That’s why -3 // 2 gives -2 instead of -1.

🔹 Modulo %
Meaning: Returns the remainder after division.

Examples:

```python
print(14 % 4)    # 14 divided by 4 → quotient 3, remainder 2 → result is 2
print(12 % 4.5)# 12 divided by 4.5 → quotient 2.0, remainder 3.0 → result is 3.0
```
How it works:

Formula: a % b = a - (a // b) * b

For 14 % 4:

14 // 4 = 3

3 * 4 = 12

14 - 12 = 2 → remainder.

For 12 % 4.5:

12 // 4.5 = 2.0

2.0 * 4.5 = 9.0

12 - 9.0 = 3.0 → remainder.
