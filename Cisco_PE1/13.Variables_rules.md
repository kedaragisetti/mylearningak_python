# Python Variables – Short Notes

## 1. Variables

- A variable is like a box that stores a value for later use.
- Every variable has a name and a value.
- Values can be changed whenever needed.

python
```
age = 20
name = "John"
```

## 2. Variable Naming Rules

- Names can contain letters, digits, and underscores (`_`).
- A name must start with a letter or underscore, not a digit.
- Python is case-sensitive: `age` and `Age` are different.
- Spaces and Python keywords are not allowed in variable names.
- Variable names can also contain Unicode letters.

python
```
my_name = "John"  # Valid
_age = 20         # Valid
2age = 20         # Invalid
```

PEP 8 convention: Use lowercase letters and underscores, e.g., `total_apples`.

## 3. Python Keywords

- Keywords are reserved words with special meanings in Python.
- They cannot be used as variable or function names.
- Python is case-sensitive, so `import` is a keyword, but `Import` is not.

Examples: `if`, `else`, `for`, `while`, `True`, `False`, `import`.

## 4. Creating Variables

- Python creates a variable automatically when a value is assigned.
- No separate declaration is required.
- The `=` operator assigns a value to a variable.

python
```
var = 10
print(var)
```

Output: `10`

## 5. Using Variables

- A variable must have a value before it is used.
- Using an undefined variable causes a `NameError`.
- Use `print()` to display values.

python
```
version = "3.8.5"
print("Python version: " + version)
```

Output: `Python version: 3.8.5`

## 6. Reassigning Variables

- Assigning a new value replaces the old value.
- `=` means assignment, not equality.
- A variable can also be updated using its current value.

python
```
var = 100
var = 200 + 300
print(var)  # 500

var = var + 1  # Increases var by 1
```

## 7. Mathematical Operations

Variables can be used in calculations with arithmetic operators.

| Operator | Meaning |
| --- | --- |
| `+` | Addition |
| `-` | Subtraction |
| `*` | Multiplication |
| `/` | Division |
| `//` | Floor division |
| `**` | Exponentiation |

Example: Pythagorean theorem

python
```
a = 3.0
b = 4.0
c = (a ** 2 + b ** 2) ** 0.5
print(c)  # 5.0
```

Formula: $c = \sqrt{a^2 + b^2}$

## 8. LAB – Total Apples

John has 3 apples, Mary has 5, and Adam has 6.

python
```
john = 3
mary = 5
adam = 6

print(john, mary, adam)

total_apples = john + mary + adam
print("Total apples:", total_apples)
```

Output:

text
```
3 5 6
Total apples: 14
```

## Quick Revision

- Variable: Stores a value.
- Assignment (`=`): Assigns or changes a value.
- Case-sensitive: `var` and `Var` are different.
- Keywords: Reserved words that cannot be used as names.
- PEP 8: Recommends lowercase names with underscores.
- NameError: Occurs when an undefined variable is used.
- Reassignment: Replaces the previous value.
- Arithmetic operators: Perform calculations using values and variables.
