# More Conditional Statements

## Finding Larger Number (2 Numbers)

```python
if num1 > num2:
    larger = num1
else:
    larger = num2
```

---

## Finding Largest Number (3 Numbers)

Idea:
- Assume first number is largest.
- Compare remaining numbers one by one.

```python
largest = num1

if num2 > largest:
    largest = num2

if num3 > largest:
    largest = num3
```

---

## Short if-else Syntax

Possible when only one statement exists.

```python
if num1 > num2: larger = num1
else: larger = num2
```

Not recommended for readability.

---

## Pseudocode

- Planning solution before coding.
- Not real Python code.

Example:

```text
Read number

If number > largest
    largest = number

Repeat
```

---

## Loop Idea

Used when same task repeats.

Example:

```text
Read Number
Compare
Read Number
Compare
Read Number
Compare
```

Instead of writing code many times, use a loop.

## max() Function

Returns largest value.

```python
largest = max(10, 20, 30)

print(largest)
```

Output:

```text
30
```

---

## min() Function

Returns smallest value.

```python
smallest = min(10, 20, 30)

print(smallest)
```

Output:

```text
10
```

## Tax Calculator Logic

```python
if income <= 85528:
    tax = income * 0.18 - 556.02
else:
    tax = 14839.02 + (income - 85528) * 0.32
```

Remember:

```python
if tax < 0:
    tax = 0
```

Used:
- if
- else
- round()

## Leap Year Logic

```python
if year % 4 != 0:
    Common Year

elif year % 100 != 0:
    Leap Year

elif year % 400 != 0:
    Common Year

else:
    Leap Year
```

Remember:
- `%` → checks divisibility
- Gregorian Calendar starts from 1582
