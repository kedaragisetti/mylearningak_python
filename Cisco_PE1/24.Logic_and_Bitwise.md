## 3.3.1 Computer Logic

### What & Why

Computers make decisions using two Boolean values: `True` and `False`. Every `if` condition, `while` loop, and input check relies on combining these yes/no answers.

### Logical Operators

| Operator | Meaning |
| :--- | :--- |
| `and` | Both conditions must be `True` |
| `or` | At least one condition must be `True` |
| `not` | Reverses `True` to `False` and vice versa |

### Truth Tables

**`and` (Conjunction)**
| A | B | A and B |
| :--- | :--- | :--- |
| `True` | `True` | `True` |
| `True` | `False` | `False` |
| `False` | `True` | `False` |
| `False` | `False` | `False` |

**`or` (Disjunction)**
| A | B | A or B |
| :--- | :--- | :--- |
| `True` | `True` | `True` |
| `True` | `False` | `True` |
| `False` | `True` | `True` |
| `False` | `False` | `False` |

**`not` (Negation)**
| A | not A |
| :--- | :--- |
| `True` | `False` |
| `False` | `True` |

### Example

```python
age = 25
has_license = True

print(age >= 18 and has_license)

# Output:
# True
```

## 3.3.2 Logical Expressions

### What & Why

Logical expressions combine multiple comparisons into a single decision.

### Key Mechanics & Gotchas

- **Short-Circuit Evaluation:** Python stops evaluating as soon as the final answer is guaranteed.
  - In `False and anything`, Python never runs `anything`.
  - In `True or anything`, Python never runs `anything`.
- **De Morgan's Laws:** Handy for simplifying negated conditions:
  - `not (A and B)` is identical to `(not A) or (not B)`
  - `not (A or B)` is identical to `(not A) and (not B)`
- **Readability Gotcha:** Avoid `if not age > 18:`. Write `if age <= 18:` instead.

### Example

```python
x = 5
print(x > 1 and x < 10)

# Python also supports chained comparisons:
print(1 < x < 10)

# Output:
# True
# True
```

## 3.3.3 Logical Values vs. Single Bits

### What & Why

Logical operators (`and`, `or`, `not`) judge whole values as truthy or falsy, whereas bitwise operators work on individual `1`s and `0`s inside integers.

### Key Mechanics & Gotchas

- In Python, `0` and empty containers are falsy; any non-zero integer is truthy.
- `bool` is a subclass of `int` (`True == 1`, `False == 0`), so `15 and 16` evaluates to `16` (the last truthy value checked), whereas `15 & 16` compares their binary bits.

### Example

```python
print(bool(15))
print(15 and 16)   # Logical AND returns the last evaluated operand
print(15 & 16)     # Bitwise AND compares binary digits

# Output:
# True
# 16
# 0
```

## 3.3.4 Bitwise Operators

### What & Why

Bitwise operators manipulate integers bit by bit. Think of binary digits like a row of light switches: `1` is ON, `0` is OFF.

### Operators & Two's Complement Formula

| Operator | Name | Rule |
| :--- | :--- | :--- |
| `&` | Bitwise AND | `1` only if **both** bits are `1` |
| `\|` | Bitwise OR | `1` if **at least one** bit is `1` |
| `^` | Bitwise XOR | `1` if the bits are **different** |
| `~` | Bitwise NOT | Flips every bit (`~x == -(x + 1)`) |

### Example

```python
# 5 in binary: 0101
# 3 in binary: 0011

print(5 & 3)   # 0001 -> 1
print(5 | 3)   # 0111 -> 7
print(5 ^ 3)   # 0110 -> 6
print(~5)      # -(5 + 1) -> -6

# Output:
# 1
# 7
# 6
# -6
```

## 3.3.5 How Do We Deal With Single Bits?

### What & Why

A **bit mask** is an integer with `1`s at the exact bit positions you want to inspect or modify. This is heavily used in permissions, hardware registers, and network flags.

### The 4 Bit-Masking Operations

Think of `flags` as a panel of switches and `mask` as the specific switch you are targeting (e.g., bit 2 -> `mask = 4`, binary `0100`):

```python
flags = 13       # Binary: 1101
mask = 4         # Binary: 0100 (targets the 3rd bit from right)

# 1. Check a bit (is it ON?)
print(bool(flags & mask))   # True

# 2. Reset a bit (force it OFF -> 0)
flags &= ~mask
print(flags)                # 9 (Binary: 1001)

# 3. Set a bit (force it ON -> 1)
flags |= mask
print(flags)                # 13 (Binary: 1101)

# 4. Toggle a bit (flip ON <-> OFF)
flags ^= mask
print(flags)                # 9 (Binary: 1001)

# Output:
# True
# 9
# 13
# 9
```

## 3.3.6 Binary Left Shift and Binary Right Shift

### What & Why

Shift operators slide all bits of an integer left or right by a given number of positions, filling empty spots with zeros (or sign bits for negative numbers).

### Key Mechanics & Gotchas

- `x << n` shifts left by `n` bits—equivalent to `x * (2 ** n)`.
- `x >> n` shifts right by `n` bits—equivalent to floor division `x // (2 ** n)`.
- Bits shifted past the right edge are permanently dropped.

### Example

```python
val = 17               # Binary: 10001

print(val << 2)        # 17 * 4 = 68 (Binary: 1000100)
print(val >> 1)        # 17 // 2 = 8 (Binary: 01000)

# Output:
# 68
# 8
```
