# Loops - while

## while Loop

- Repeats code as long as condition is `True`.
- Similar to `if`, but runs multiple times.

```python
counter = 5

while counter > 0:
    print(counter)
    counter -= 1
```

Output:

```text
5
4
3
2
1
```

---

## Syntax

```python
while condition:
    statement
```

---

## Loop Body

- Code inside the loop.
- Must be indented.

```python
while x > 0:
    print(x)
    x -= 1
```

---

## Infinite Loop

- Condition never becomes `False`.

```python
while True:
    print("Running...")
```

- Stops only when program is interrupted.

---

## Finding Largest Number

```python
largest = -999999999

number = int(input())

while number != -1:

    if number > largest:
        largest = number

    number = int(input())

print(largest)
```

Special value:

```python
-1
```

used as a sentinel value (stop signal).

---

## Counting Odd and Even Numbers

```python
odd = 0
even = 0

number = int(input())

while number != 0:

    if number % 2:
        odd += 1
    else:
        even += 1

    number = int(input())

print("Odd:", odd)
print("Even:", even)
```

Stop value:

```python
0
```

---

## Counter Controlled Loop

```python
counter = 5

while counter:
    print(counter)
    counter -= 1
```

Same as:

```python
while counter != 0:
```

Because:

```python
0      -> False
non-zero -> True
```

---

## Simplified Conditions

```python
while number != 0:
```

can be written as

```python
while number:
```

---

```python
if number % 2 == 1:
```

can be written as

```python
if number % 2:
```

---

## Remember

- `while` runs until condition becomes `False`.
- Loop body must be indented.
- Update condition inside loop to avoid infinite loops.
- `True` creates an infinite loop.
- `0` is treated as `False`.
- Non-zero values are treated as `True`.
- Sentinel values like `-1` or `0` are commonly used to stop loops.
