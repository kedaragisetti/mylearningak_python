# 3.6 Operations on Lists

## 3.6.1 The Inner Life of Lists

### What & Why

Unlike simple integers, a list variable does not store the items directly—it stores a **memory reference** (like a sticky note pointing to where the box of items lives in memory).

### Key Mechanics & Gotchas

- Writing `list_2 = list_1` copies the *reference*, not the list itself. Modifying `list_2` also mutates `list_1`!

### Example

```python
list_1 = [1, 2, 3]
list_2 = list_1       # Both point to the SAME list in memory
list_2[0] = 99

print("list_1:", list_1)
print("list_2:", list_2)

# Output:
# list_1: [99, 2, 3]
# list_2: [99, 2, 3]
```

## 3.6.2 Powerful Slices

### What & Why

Slicing (`my_list[start:end]`) extracts a brand-new list containing elements from `start` up to `end - 1`.

### Key Mechanics & Gotchas

- `my_list[:]` copies the entire list safely, breaking the aliasing link.
- Omitting `start` defaults to `0` (`my_list[:3]`); omitting `end` goes to the end (`my_list[2:]`).
- `del my_list[1:3]` deletes a slice in place; `del my_list[:]` empties the list; `del my_list` deletes the variable itself.

### Example

```python
colors = ["red", "green", "blue", "yellow", "purple"]

copy_all = colors[:]          # Independent shallow copy
middle = colors[1:4]          # Indices 1, 2, 3
first_two = colors[:2]        # Indices 0, 1

del colors[1:3]               # Removes "green" and "blue"

print("Middle:", middle)
print("First two:", first_two)
print("After del slice:", colors)
print("Original copy intact:", copy_all)

# Output:
# Middle: ['green', 'blue', 'yellow']
# First two: ['red', 'green']
# After del slice: ['red', 'yellow', 'purple']
# Original copy intact: ['red', 'green', 'blue', 'yellow', 'purple']
```

## 3.6.3 Slices – Negative Indices

### What & Why

Both `start` and `end` in a slice can be negative, letting you grab items relative to the tail of the list.

### Key Mechanics & Gotchas

- If `start` resolves to an index after `end` (e.g., `my_list[-1:-3]`), Python returns an empty list `[]` rather than an error.

### Example

```python
nums = [10, 20, 30, 40, 50]

print(nums[-3:-1])    # From 3rd-from-end up to (but not including) last
print(nums[-2:])      # Last two items

# Output:
# [30, 40]
# [40, 50]
```

## 3.6.4 The `in` and `not in` Operators

### What & Why

Membership operators check whether a value exists anywhere in a list, returning `True` or `False` without needing a manual loop.

### Example

```python
my_list = [0, 3, 12, 8, 2]

print(5 in my_list)
print(5 not in my_list)
print(12 in my_list)

# Output:
# False
# True
# True
```

## 3.6.5 Lists – Some Simple Programs

### Finding the Largest Value

```python
my_list = [17, 3, 11, 5, 1, 9, 7, 15, 13]
largest = my_list[0]

for num in my_list[1:]:
    if num > largest:
        largest = num

print("Largest:", largest)

# Output:
# Largest: 17
```

### Counting Lottery Hits

```python
drawn = [5, 11, 9, 42, 3, 49]
bets = [3, 7, 11, 42, 34, 49]
hits = 0

for number in bets:
    if number in drawn:
        hits += 1

print("Hits:", hits)

# Output:
# Hits: 4
```

# 3.7 Lists in Advanced Applications

## 3.7.1 Lists in Lists

### What & Why

A list can hold any data type—including other lists. **List comprehensions** give you a clean one-line syntax to build lists dynamically.

### Example

```python
squares = [x ** 2 for x in range(6)]
odds = [x for x in squares if x % 2 != 0]

print("Squares:", squares)
print("Odd squares:", odds)

# Output:
# Squares: [0, 1, 4, 9, 16, 25]
# Odd squares: [1, 9, 25]
```

## 3.7.2 Two-Dimensional Arrays

### What & Why

A list of lists models a 2D grid (rows and columns), accessed with two brackets: `board[row][column]`.

### Key Mechanics & Gotchas

- **Aliasing Trap:** Never initialize a 2D grid with `[[0] * 8] * 8`. That duplicates the *same row reference* 8 times, so changing `board[0][0]` changes every row! Always use nested list comprehensions.

### Example

```python
EMPTY = "-"
board = [[EMPTY for col in range(8)] for row in range(8)]

board[0][0] = "ROOK"
board[0][7] = "ROOK"
board[7][0] = "ROOK"
board[7][7] = "ROOK"

print(board[0])
print(board[1])

# Output:
# ['ROOK', '-', '-', '-', '-', '-', '-', 'ROOK']
# ['-', '-', '-', '-', '-', '-', '-', '-']
```

## 3.7.3 Multidimensional Nature of Lists: Advanced Applications

### What & Why

Python lets you nest lists to any depth. A 3D list works like a hotel address: `rooms[building][floor][room]`.

### Example

```python
# 3 buildings, 15 floors each, 20 rooms per floor (False = vacant)
rooms = [[[False for r in range(20)] for f in range(15)] for t in range(3)]

# Book a room in Building 1, Floor 10, Room 14 (0-indexed)
rooms[1][9][13] = True

# Count vacancies on Floor 15 of Building 3
vacancy = 0
for room_num in range(20):
    if not rooms[2][14][room_num]:
        vacancy += 1

print("Booked status:", rooms[1][9][13])
print("Vacant rooms on top floor of Building 3:", vacancy)

# Output:
# Booked status: True
# Vacant rooms on top floor of Building 3: 20
```
