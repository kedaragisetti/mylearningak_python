# for Loop

## Why for?

- Used when number of iterations is known.
- Automatically handles counting.

Instead of:

```python
i = 0

while i < 5:
    print(i)
    i += 1
```

Use:

```python
for i in range(5):
    print(i)
```

---

## Syntax

```python
for variable in range(n):
    statement
```

---

## range()

Generates a sequence of numbers.

### One Argument

```python
for i in range(5):
    print(i)
```

Output:

```text
0
1
2
3
4
```

Note:
- Starts from `0`
- Stops before `5`

---

### Two Arguments

```python
for i in range(2, 8):
    print(i)
```

Output:

```text
2
3
4
5
6
7
```

Format:

```python
range(start, stop)
```

---

### Three Arguments

```python
for i in range(2, 8, 3):
    print(i)
```

Output:

```text
2
5
```

Format:

```python
range(start, stop, step)
```

---

## Empty Range

```python
for i in range(1, 1):
    print(i)
```

Output:

```text
No Output
```

---

```python
for i in range(2, 1):
    print(i)
```

Output:

```text
No Output
```

---

## pass

- Empty statement.
- Used when Python expects code but nothing should happen.

```python
for i in range(5):
    pass
```
