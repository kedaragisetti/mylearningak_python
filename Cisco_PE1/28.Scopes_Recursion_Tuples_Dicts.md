# 4.4 Scopes in Python

## 4.4.1 Functions and Scopes

### What & Why

**Scope** determines where a variable is visible. Variables created inside a function are **local** to that function and vanish when it finishes.

### Key Mechanics & Gotchas

- A function can *read* a global variable defined outside it, **unless** it assigns to a variable with the same name—which creates a separate local variable that **shadows** the global one.

### Example

```python
var = 2

def show_shadow():
    var = 1        # Creates a local 'var', leaving global 'var' untouched
    print("Inside:", var)

show_shadow()
print("Outside:", var)

# Output:
# Inside: 1
# Outside: 2
```

---

## 4.4.2 Functions and Scopes: The `global` Keyword

### What & Why

Adding `global var_name` inside a function tells Python not to create a local copy, allowing the function to modify the outer global variable directly.

### Example

```python
var = 2

def update_global():
    global var
    var = 5
    print("Inside:", var)

update_global()
print("Outside:", var)

# Output:
# Inside: 5
# Outside: 5
```

---

## 4.4.3 How the Function Interacts With Its Arguments

### What & Why

Understanding how functions treat passed arguments prevents subtle mutation bugs.

### Key Mechanics & Gotchas

- **Reassigning** a parameter (`lst = [4, 5]`) only points the local parameter name to a new object—the caller's list stays unchanged.
- **Mutating in place** (`del lst[0]` or `lst.append(9)`) modifies the actual list object shared with the caller.

### Example

```python
def test_list(my_list):
    del my_list[0]         # Mutates caller's list in place
    my_list = [99, 100]    # Rebinds local parameter only

nums = [1, 2, 3]
test_list(nums)
print(nums)

# Output:
# [2, 3]
```

# 4.5 Creating Multi-Parameter Functions

## 4.5.1 Sample Functions: Evaluating the BMI

### Core Logic

$$\text{BMI} = \frac{\text{weight in kg}}{(\text{height in meters})^2}$$

Helper functions convert imperial pounds and feet/inches cleanly before computing BMI.

### Solution

```python
def lb_to_kg(lb):
    return lb * 0.45359237

def ft_and_inch_to_m(ft, inch=0.0):
    return ft * 0.3048 + inch * 0.0254

def bmi(weight, height):
    if height < 1.0 or height > 2.5 or weight < 20 or weight > 200:
        return None
    return weight / height ** 2

print(round(bmi(weight=lb_to_kg(176), height=ft_and_inch_to_m(5, 7)), 2))

# Output:
# 27.57
```

## 4.5.2 Sample Functions: Triangles

### Core Logic

1. **Triangle inequality:** Three sides form a valid triangle only if the sum of any two sides is strictly greater than the third.
2. **Heron's formula:** Area $= \sqrt{s(s-a)(s-b)(s-c)}$, where $s = \frac{a+b+c}{2}$.

### Solution

```python
def is_a_triangle(a, b, c):
    return a + b > c and b + c > a and c + a > b

def heron(a, b, c):
    s = (a + b + c) / 2
    return (s * (s - a) * (s - b) * (s - c)) ** 0.5

def area_of_triangle(a, b, c):
    if not is_a_triangle(a, b, c):
        return None
    return heron(a, b, c)

print(area_of_triangle(3.0, 4.0, 5.0))

# Output:
# 6.0
```

## 4.5.3 Sample Functions: Factorials

### Core Logic

$n! = 1 \times 2 \times 3 \times \dots \times n$, with $0! = 1$ and $1! = 1$.

### Solution

```python
def factorial_function(n):
    if n < 0:
        return None
    product = 1
    for i in range(2, n + 1):
        product *= i
    return product

for n in range(1, 6):
    print(n, "->", factorial_function(n))

# Output:
# 1 -> 1
# 2 -> 2
# 3 -> 6
# 4 -> 24
# 5 -> 120
```

## 4.5.4 Fibonacci Numbers

### Core Logic

Each Fibonacci number is the sum of the two preceding ones: `1, 1, 2, 3, 5, 8, 13...`

### Solution

```python
def fib(n):
    if n < 1:
        return None
    if n < 3:
        return 1
    elem_1 = elem_2 = 1
    the_sum = 0
    for i in range(3, n + 1):
        the_sum = elem_1 + elem_2
        elem_1, elem_2 = elem_2, the_sum
    return the_sum

for n in range(1, 8):
    print(n, "->", fib(n))

# Output:
# 1 -> 1
# 2 -> 1
# 3 -> 2
# 4 -> 3
# 5 -> 5
# 6 -> 8
# 7 -> 13
```

## 4.5.5 Recursion

### What & Why

**Recursion** is a technique where a function calls itself to solve smaller sub-versions of the same problem.

### Key Mechanics & Gotchas

- Every recursive function needs two parts:
  1. **Base case:** A stopping condition that returns directly without recursing.
  2. **Recursive step:** Moves closer to the base case.
- Missing a base case causes infinite calls and crashes with `RecursionError`.

### Example

```python
def factorial_recursive(n):
    if n < 0:
        return None
    if n < 2:          # Base case
        return 1
    return n * factorial_recursive(n - 1)   # Recursive step

print(factorial_recursive(5))

# Output:
# 120
```

# 4.6 Tuples and Dictionaries

## 4.6.1 Sequence Types and Mutability

### What & Why

- **Sequence types** (lists, tuples, strings) store items in numbered index order.
- **Mutability** determines whether data can be modified in place after creation:
  - **Mutable:** `list`, `dict` (can add, remove, or change elements in place).
  - **Immutable:** `tuple`, `str`, `int`, `float` (cannot be altered in place; operations create new objects).

---

## 4.6.2 Tuples

### What & Why

A **tuple** is an immutable sequence, typically written with parentheses `()`. Use tuples for fixed records (coordinates, RGB colors) that shouldn't accidentally change.

### Key Mechanics & Gotchas

- **Single-element tuple trap:** `(1)` is just the integer `1`. You **must** include a trailing comma: `(1,)` or `1,`.
- Attempting `my_tuple[0] = 5` or `my_tuple.append(5)` raises a `TypeError` or `AttributeError`.
- Tuples support `len()`, indexing/slicing, `in`/`not in`, `+` (concatenation), `*` (repetition), and tuple unpacking (`a, b = (10, 20)`).

### Example

```python
one_elem = (42,)
t1 = (1, 10, 100)
t2 = t1 + (1000,)

print(type(one_elem))
print(t2)
print(len(t2))

# Output:
# <class 'tuple'>
# (1, 10, 100, 1000)
# 4
```

## 4.6.3 Dictionaries

### What & Why

A **dictionary** (`dict`) stores **key-value pairs** (`{key: value}`), working like a phonebook where you look up a value by its key rather than a numeric index.

### Key Mechanics & Gotchas

- Keys must be **unique** and **immutable** (strings, numbers, tuples—never lists).
- Since Python 3.7+, dictionaries preserve insertion order.
- Looking up a missing key with `d["missing"]` raises a `KeyError`. Check with `"missing" in d` or use `d.get("missing")` (which safely returns `None`).

### Example

```python
dictionary = {"cat": "chat", "dog": "chien", "horse": "cheval"}
words = ["cat", "lion", "horse"]

for word in words:
    if word in dictionary:
        print(word, "->", dictionary[word])
    else:
        print(word, "is not in dictionary")

# Output:
# cat -> chat
# lion is not in dictionary
# horse -> cheval
```

---

## 4.6.4 Dictionary Methods and Functions

### What & Why

Dictionaries come with dedicated methods for iterating, updating, and removing pairs.

### Essential Operations

- `d.keys()` -> iterable of all keys (wrap in `sorted(d.keys())` to sort).
- `d.values()` -> iterable of all values.
- `d.items()` -> iterable of `(key, value)` tuples.
- `d[key] = val` or `d.update({key: val})` -> adds a new pair or updates an existing key.
- `del d[key]` -> deletes a specific key-value pair.
- `d.popitem()` -> removes and returns the **last inserted** `(key, value)` pair.

### Example

```python
animals = {"cat": "chat", "dog": "chien"}
animals["swan"] = "cygne"        # Add new entry
animals.update({"duck": "canard"})

for eng, fr in sorted(animals.items()):
    print(eng, "->", fr)

del animals["dog"]
print("After del:", animals)

# Output:
# cat -> chat
# dog -> chien
# duck -> canard
# swan -> cygne
# After del: {'cat': 'chat', 'swan': 'cygne', 'duck': 'canard'}
```

## 4.6.5 Tuples and Dictionaries Can Work Together

### What & Why

Combining dictionaries (mapping names to data) with tuples (storing immutable score histories) is a classic pattern for aggregating records.

### Example

```python
school_class = {
    "Bob": (7, 8, 9),
    "Andy": (6, 10)
}

for name in sorted(school_class.keys()):
    scores = school_class[name]
    average = sum(scores) / len(scores)
    print(name, ":", round(average, 2))

# Output:
# Andy : 8.0
# Bob : 8.0
```
