# 3.4 Lists

## 3.4.1 Why Do We Need Lists?

### What & Why

Creating `score1`, `score2`, `score3` doesn't scale when you have dozens or thousands of values. A **list** is an ordered, changeable (mutable) collection stored under a single variable name.

### Example

```python
numbers = [10, 5, 7, 2, 1]
print(numbers)

# Output:
# [10, 5, 7, 2, 1]
```

---

## 3.4.2 Indexing Lists

### What & Why

Every item in a list has a numbered position called an **index**, starting at `0` for the first element.

### Key Mechanics & Gotchas

- Attempting to read or assign an index that doesn't exist raises an `IndexError`.
- You can overwrite an existing element directly using `my_list[index] = new_value`.

### Example

```python
numbers = [10, 5, 7, 2, 1]
numbers[0] = 111
numbers[1] = numbers[4]

print(numbers)

# Output:
# [111, 1, 7, 2, 1]
```

---

## 3.4.3 Accessing List Content

### What & Why

The built-in `len()` function tells you how many elements are currently inside a list.

### Example

```python
numbers = [10, 20, 30, 40]
print("Length:", len(numbers))

# Output:
# Length: 4
```

---

## 3.4.4 Removing Elements From a List

### What & Why

The `del` instruction removes an item at a specific index and automatically shifts all remaining items left to close the gap.

### Key Mechanics & Gotchas

- `del` is a **statement**, not a function (no parentheses needed).
- Once deleted with `del`, the value is gone unless you saved it beforehand.

### Example

```python
numbers = [10, 20, 30, 40]
del numbers[1]

print(numbers)
print("New length:", len(numbers))

# Output:
# [10, 30, 40]
# New length: 3
```

---

## 3.4.5 Negative Indices Are Legal

### What & Why

Negative indices count backward from the end of a list, saving you from writing `my_list[len(my_list) - 1]`.

### Key Mechanics & Gotchas

- `-1` is always the last element; `-2` is second-to-last.
- Going further back than `-len(my_list)` still triggers an `IndexError`.

### Example

```python
numbers = [111, 7, 2, 1]
print(numbers[-1])
print(numbers[-2])

# Output:
# 1
# 2
```

## 3.4.6 LAB – The Basics of Lists

### Core Logic

1. Start with `[1, 2, 3, 4, 5]`.
2. Replace the middle element (index `2`) with an integer from the user.
3. Delete the last element using `-1`.
4. Print the updated length and the list.

### Solution

```python
hat_list = [1, 2, 3, 4, 5]

hat_list[2] = int(input("Enter a number for the middle of the hat: "))
del hat_list[-1]

print("List length:", len(hat_list))
print(hat_list)
```

## 3.4.7 Functions vs. Methods

### What & Why

Both do work, but they are called differently:
- A **function** stands on its own and takes data inside parentheses: `len(my_list)`.
- A **method** belongs to an object and is called with dot notation: `my_list.append(5)`.

### Key Mechanics & Gotchas

- Methods like `.append()` and `.insert()` modify the list **in place** and return `None`. Never write `my_list = my_list.append(5)`—that overwrites your list with `None`!

---

## 3.4.8 Adding Elements to a List: `append()` and `insert()`

### What & Why

Lists grow dynamically. Use `.append()` to add to the end, or `.insert()` to place an item at any index.

### Example

```python
numbers = [111, 7, 2, 1]

numbers.append(4)         # Adds 4 to the end
numbers.insert(0, 222)    # Places 222 at index 0, shifting others right

print(numbers)

# Output:
# [222, 111, 7, 2, 1, 4]
```

## 3.4.9 Making Use of Lists

### What & Why

Loops and lists are built for each other. You can iterate directly over elements (`for x in my_list:`) or over indices (`for i in range(len(my_list)):`) when you need to swap or modify positions.

### Swapping & Reversing In Place

```python
my_list = [10, 1, 8, 3, 5]
length = len(my_list)

# Swap symmetric pairs from outer edges toward the center
for i in range(length // 2):
    my_list[i], my_list[length - i - 1] = my_list[length - i - 1], my_list[i]

print(my_list)

# Output:
# [5, 3, 8, 1, 10]
```

## 3.4.10 Lists in Action

### What & Why

Combining loops with accumulator variables lets you summarize any list cleanly.

### Example

```python
numbers = [10, 1, 8, 3, 5]
total = 0

for num in numbers:
    total += num

print("Total:", total)

# Output:
# Total: 27
```

# 3.5 Sorting Simple Lists: The Bubble Sort Algorithm

## 3.5.1 The Bubble Sort

### What & Why

Bubble sort compares adjacent elements and swaps them if they are in the wrong order. With each full pass, the largest unsorted element "bubbles up" to its final position at the end.

### Step-by-Step Intuition

Starting with `[8, 10, 6, 2, 4]`:
1. Compare `8` and `10` -> in order.
2. Compare `10` and `6` -> swap -> `[8, 6, 10, 2, 4]`.
3. Compare `10` and `2` -> swap -> `[8, 6, 2, 10, 4]`.
4. Compare `10` and `4` -> swap -> `[8, 6, 2, 4, 10]` (`10` is now locked in).
5. Repeat passes until a pass finishes with zero swaps.

---

## 3.5.2 Sorting a List

### What & Why

Using a `swapped` flag stops the algorithm early as soon as the list is sorted. In real Python projects, you'll usually use the built-in `.sort()` method.

### Example

```python
my_list = [8, 10, 6, 2, 4]
swapped = True

while swapped:
    swapped = False
    for i in range(len(my_list) - 1):
        if my_list[i] > my_list[i + 1]:
            swapped = True
            my_list[i], my_list[i + 1] = my_list[i + 1], my_list[i]

print("Bubble sorted:", my_list)

# Built-in alternatives:
nums = [8, 10, 6, 2, 4]
nums.sort()
print("Built-in sort:", nums)
nums.reverse()
print("Reversed:", nums)

# Output:
# Bubble sorted: [2, 4, 6, 8, 10]
# Built-in sort: [2, 4, 6, 8, 10]
# Reversed: [10, 8, 6, 4, 2]
```

---

## 3.5.3 The Bubble Sort – Interactive Version

### Core Logic

1. Ask the user how many numbers they want to sort.
2. Append each input number into a list.
3. Run the `while swapped:` bubble sort loop and print the sorted list.

### Solution

```python
my_list = []
swapped = True
num = int(input("How many elements do you want to sort: "))

for i in range(num):
    val = float(input("Enter a list element: "))
    my_list.append(val)

while swapped:
    swapped = False
    for i in range(len(my_list) - 1):
        if my_list[i] > my_list[i + 1]:
            swapped = True
            my_list[i], my_list[i + 1] = my_list[i + 1], my_list[i]

print("Sorted:", my_list)
```
