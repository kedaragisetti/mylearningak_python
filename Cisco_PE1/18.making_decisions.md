# Making Decisions

## Comparison Operators

Used to ask questions in Python.

```python
2 == 2
```

Output:

```text
True
```

---

## Equality Operator `==`

Checks if two values are equal.

```python
print(2 == 2)
print(1 == 2)
```

Output:

```text
True
False
```

---

## Not Equal Operator `!=`

Checks if two values are different.

```python
print(1 != 0)
print(0 != 0)
```

Output:

```text
True
False
```

---

## Greater Than `>`

```python
print(10 > 5)
```

Output:

```text
True
```

---

## Greater Than or Equal `>=`

```python
print(100 >= 100)
```

Output:

```text
True
```

---

## Less Than `<`

```python
print(5 < 10)
```

Output:

```text
True
```

---

## Less Than or Equal `<=`

```python
print(10 <= 10)
```

Output:

```text
True
```

---

## Boolean Values

Python returns:

```python
True
False
```

from comparison operations.

---

```python
result = 10 > 5

print(result)
```

Output:

```text
True
```

# if Statement

Runs code only when condition is True.

```python
age = 18

if age >= 18:
    print("Adult")
```

Output:

```text
Adult
```

---

## Indentation

Python uses 4 spaces for blocks.

```python
if 5 > 2:
    print("True")
```

---

# if - else

Choose between two paths.

```python
age = 16

if age >= 18:
    print("Adult")
else:
    print("Minor")
```

Output:

```text
Minor
```

---

# Nested if

An if inside another if.

```python
if weather_good:
    if restaurant_found:
        have_lunch()
```

---

# elif

Used for multiple conditions.

```python
marks = 75

if marks >= 90:
    print("A")
elif marks >= 75:
    print("B")
else:
    print("C")
```

Output:

```text
B
```

---

# Remember

- `=` → Assignment
- `==` → Equal to
- `!=` → Not equal to
- `>` → Greater than
- `>=` → Greater than or equal to
- `<` → Less than
- `<=` → Less than or equal to

Conditional Statements:

- `if`
- `if-else`
- `if-elif-else`
- Nested `if`

Only code inside the indented block belongs to the condition.
