# Input_Output

## input()

- Used to take input from the user.
- Always returns a string.

```python
name = input("Enter your name: ")

print(name)
```

---

## Type Casting

- Convert input into a number.
- `int()` → Integer
- `float()` → Decimal

```python
age = int(input("Enter age: "))
salary = float(input("Enter salary: "))
```

---

## String Concatenation

- `+` joins strings.

```python
print("Hello" + " World")
```

Output:

```text
Hello World
```

---

## String Replication

- `*` repeats a string.

```python
print("Hi " * 3)
```

Output:

```text
Hi Hi Hi
```

## LAB - Simple Calculator

```python
num1 = float(input("Enter first value: "))
num2 = float(input("Enter second value: "))

print(num1 + num2)
print(num1 - num2)
print(num1 * num2)
print(num1 / num2)
```

## LAB - End Time

```python
total_minutes = hour * 60 + minute + duration

end_hour = (total_minutes // 60) % 24
end_minute = total_minutes % 60
```

Used:
- `//` → Hours
- `%` → Remaining minutes

---

## Remember

1. `print()` → Output
2. `input()` → Input
3. `input()` always returns `str`
4. Use `int()` or `float()` for calculations
5. `+` joins strings
6. `*` repeats strings
