# Loops - Summary

## Types of Loops

### while

Runs while condition is `True`.

```python
counter = 5

while counter > 0:
    print(counter)
    counter -= 1
```

---

### for

Runs a fixed number of times or over a sequence.

```python
for i in range(5):
    print(i)
```

Output:

```text
0 1 2 3 4
```

---

## break

Exits loop immediately.

```python
for i in range(10):

    if i == 5:
        break

    print(i)
```

Output:

```text
0 1 2 3 4
```

---

## continue

Skips current iteration.

```python
for i in range(5):

    if i == 2:
        continue

    print(i)
```

Output:

```text
0 1 3 4
```

---

## Loop else

Runs only if loop finishes normally.

```python
for i in range(3):
    print(i)
else:
    print("Done")
```

Output:

```text
0
1
2
Done
```

---
