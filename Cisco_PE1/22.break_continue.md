# for Loop - Advanced

## for vs while

```python
while
```

- Runs while a condition is True.

```python
for
```

- Runs a fixed number of times.
- Good for counting iterations.

---

## Basic for Loop

```python
for i in range(5):
    print(i)
```

Output:

```text
0
1
2
3
4
```

Remember:
- Starts from `0`
- Stops before `5`

---

## range()

### One Argument

```python
range(5)
```

```text
0 1 2 3 4
```

---

### Two Arguments

```python
range(2, 8)
```

```text
2 3 4 5 6 7
```

Format:

```python
range(start, stop)
```

---

### Three Arguments

```python
range(2, 8, 3)
```

```text
2 5
```

Format:

```python
range(start, stop, step)
```
