### Python Boolean Values

- **Booleans = truth values** → `True`, `False`.  
- Case‑sensitive → must be written exactly as `True` or `False`.  
- Represented internally as `1` (True) and `0` (False).  
- Used in comparisons → results are Boolean.  
- Only two answers: True or False (no “maybe”).  

---

## 🔢 Example Code

```python
print(True > False)   
print(True < False)  

# Booleans behave like integers
print(True + True)    
print(False + 5)      
print(True * 10)
