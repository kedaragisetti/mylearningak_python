# Shortcut Operators

##  Idea
- Often we use the same variable on both sides of `=`.
- Example:
```python
x = x * 2
sheep = sheep + 1
```

👉 Python gives a shorter way:
```python
x *= 2
sheep += 1
```

---

## 📌 General Form
If `op` is a two‑argument operator:

```python
variable = variable op expression
```

can be written as:

```python
variable op= expression
```

---

## 🧮 Examples

### Addition
```python
counter = 0
counter += 1
print(counter)   # → 1
```

### Subtraction
```python
value = 10
value -= 3
print(value)   # → 7
```

### Multiplication
```python
x = 5
x *= 2
print(x)   # → 10
```

### Division
```python
num = 20
num /= 4
print(num)   # → 5.0
```

### Floor Division
```python
a = 17
a //= 3
print(a)   # → 5
```

### Modulus
```python
b = 10
b %= 3
print(b)   # → 1
```

### Exponentiation
```python
c = 2
c **= 3
print(c)   # → 8
```

---

## 📖 Summary
- Shortcut operators save time and make code cleaner.  
- Pattern: `var op= expr` instead of `var = var op expr`.  
- Works with `+`, `-`, `*`, `/`, `//`, `%`, `**`.  
- Useful for counters, loops, and repeated calculations.

## A Simple Converter

## 🔑 Scenario
- 1 mile ≈ 1.61 kilometers  
- Task: convert miles → kilometers and kilometers → miles.  
- Use variables, arithmetic, and `print()` with multiple arguments.  
- Use `round()` to control decimal places.

---

## 🧮 Miles ↔ Kilometers Converter
```python
miles = 7.38
kilometers = 12.25

# Convert miles to kilometers
miles_to_km = miles * 1.61

# Convert kilometers to miles
km_to_miles = kilometers / 1.61

print(miles, "miles is", round(miles_to_km, 2), "kilometers")
print(kilometers, "kilometers is", round(km_to_miles, 2), "miles")
```

👉 **Output:**
```
7.38 miles is 11.88 kilometers
12.25 kilometers is 7.61 miles
```

## USD ↔ INR Converter
```python
USD = 1
INR = 10

# Conversion rate: 1 USD = 94.45 INR
# To get INR from USD, multiply by the rate
USD_to_INR = USD * 94.45

# To get USD from INR, divide by the rate
INR_to_USD = INR / 94.45

print(INR, "INR to USD is", round(INR_to_USD, 3), "USD")
print(USD, "USD to INR is", round(USD_to_INR, 3), "INR")
```

👉 **Output:**
```
10 INR to USD is 0.106 USD
1 USD to INR is 94.45 INR
```
