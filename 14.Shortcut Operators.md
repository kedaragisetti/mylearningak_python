# Shortcut Operators

##  Idea
- Often we use the same variable on both sides of `=`.
- Example:
```python
x = x * 2
sheep = sheep + 1
```

👉 Python gives a shorter way:
```python
x *= 2
sheep += 1
```

---

## 📌 General Form
If `op` is a two‑argument operator:

```python
variable = variable op expression
```

can be written as:

```python
variable op= expression
```

---

## 🧮 Examples

### Addition
```python
counter = 0
counter += 1
print(counter)   # → 1
```

### Subtraction
```python
value = 10
value -= 3
print(value)   # → 7
```

### Multiplication
```python
x = 5
x *= 2
print(x)   # → 10
```

### Division
```python
num = 20
num /= 4
print(num)   # → 5.0
```

### Floor Division
```python
a = 17
a //= 3
print(a)   # → 5
```

### Modulus
```python
b = 10
b %= 3
print(b)   # → 1
```

### Exponentiation
```python
c = 2
c **= 3
print(c)   # → 8
```

---

## 📖 Summary
- Shortcut operators save time and make code cleaner.  
- Pattern: `var op= expr` instead of `var = var op expr`.  
- Works with `+`, `-`, `*`, `/`, `//`, `%`, `**`.  
- Useful for counters, loops, and repeated calculations.
