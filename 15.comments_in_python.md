# Comments in Python

##  Why Comments?
- Comments = notes for humans, ignored by Python at runtime.
- Used to explain code, variables, logic, or author info.
- Help future readers (including yourself) understand code.
- Best practice: use **self‑commenting variable names** (e.g., `square_area` instead of `aunt_jane`).

---

## How to Write Comments
- Start with `#` → extends to end of line.
- For multi‑line comments → put `#` at the start of each line.

Example:
```python
# This program evaluates the hypotenuse c.
# a and b are the lengths of the legs.
a = 3.0
b = 4.0
c = (a ** 2 + b ** 2) ** 0.5  # Using ** instead of sqrt
print("c =", c)
