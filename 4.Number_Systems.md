## 📝 Python Number Systems — Quick Notes

- **Decimal (base‑10)** → normal numbers (`25`).  
- **Binary (base‑2)** → prefix `0b` (`0b11001`).  
- **Octal (base‑8)** → prefix `0o` (`0o31`).  
- **Hexadecimal (base‑16)** → prefix `0x` (`0x19`).  

---

## 🔢 Example

```python
decimal = 25
binary = 0b11001
octal = 0o31
hexadecimal = 0x19

print(decimal)      # 25
print(binary)       # 25
print(octal)        # 25
print(hexadecimal)  # 25
```

This keeps it **compact and exam‑ready** — easy to glance through and recall prefixes + usage.
