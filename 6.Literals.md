# Python Literals

Literals are values written directly in Python code. Common examples include integers, floating-point numbers, strings and Boolean values.

## Example

```python
age = 27
price = 99.5
name = "Kedar"
is_learning = True

print(age, price, name, is_learning)
```

## How it works

- `27` is an integer literal.
- `99.5` is a floating-point literal.
- `"Kedar"` is a string literal.
- `True` is a Boolean literal.

These values are assigned to variables.
