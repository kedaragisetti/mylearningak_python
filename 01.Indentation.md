# Python Indentation

Indentation means adding spaces at the beginning of a line. Python uses indentation to identify which statements belong inside a condition, loop, or function.

## Example

```python
number = 10

if number > 5:
    print("Big number")
```

## How it works

The `if` condition checks whether `number` is greater than 5. The `print()` statement is indented because it belongs to the `if` block.

Python usually uses four spaces for indentation.
